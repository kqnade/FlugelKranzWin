# FlugelKranzWin

Windows x64 / SteamVR 向けの自由飛行・無限歩行ツールです。慣性付き Space Drag と、Pitch / Yaw / Roll の全 3 軸回転を組み合わせて空間を移動できます。アプリ名・実行ファイル名は `FlugelKranz` です。

このリポジトリは [FlugelKranz](https://github.com/ReinaS-64892/FlugelKranz) の Windows 向け派生版です。ここでの開発・配布・サポート対象は Windows / SteamVR に限定します。**Linux / Monado / WiVRn 版は親リポジトリを参照してください。** 上流由来の Linux 関連コードは残っていますが、このリポジトリの対応対象ではありません。

## 導入

Windows x64、SteamVR、対応 HMD・コントローラー、および同梱の専用 SteamVR ドライバーが必要です。[ビルド・導入・更新手順](WINDOWS.md) に従ってアプリとドライバーを配置し、フレーム姿勢補正を設定してください。

Quest 2 + Touch / Virtual Desktop では、時刻ベースの補正を有効にした構成で、回転保持中および回転操作中の頭部運動で、黒い縁・暗転・ジッターが改善したとの実機報告を得ています（2026-09-13）。その後に報告された視界のふらつきも、恒等変換時のパススルーと回転保持中の元のフレーム予測を維持する修正後、解消したとの実機報告を得ています（2026-09-14）。設定と検証範囲は [WINDOWS.md](WINDOWS.md#動作確認) に記載しています。

## 最初の操作

1. SteamVR を起動し、HMD と左右コントローラーが追跡されている状態で `FlugelKranz.exe` を起動します。
2. `F` モードを選び、ON にします。操作ボタンは一度離してから押してください。
3. Touch のグリップを押しながら手を動かすと空間を引っ張ります。動かしている途中で離すと、設定に応じて慣性が残ります。
4. 左 X / 右 A を押して手首を回すと全 3 軸で回転します。
5. OFF は飛行と慣性を止めます。F モードで Drag が有効なら Drag のみ操作でき、`↻` は位置・姿勢を元に戻します。

## 操作仕様

### 起動と共通操作

Windows では OFF で起動し、保存済みのモードを復元します。SteamVR と専用ドライバーを起動してから ON にしてください。接続できない場合は設定画面にエラーを表示します。大きな `ON` / `OFF` ボタンは現在の動作状態を表し、押すと切り替わります。OFF にしても現在の位置・姿勢は保持しますが、操作中の掴みと慣性は終了します。F モードで Drag が有効なら、入力を離して掴み直すことで Drag だけ使用できます。飛行 OFF 中は頭部操縦・スティック推進・解放時の慣性は無効です。Drag も無効にすると空間操作は停止します。

丸い `I` / `F` ボタンは無限歩行（Infinite Walking）と自由飛行（Free Flight）の切替、`⚙` は設定、`↻` は接続時の位置・姿勢への全体リセットです。全体リセットは ON を維持したまま直ちに位置・姿勢を戻します。ON にした後、モード切替後、全体リセット後は、押したままの操作入力を一度離してから掴み直してください。

無限歩行から自由飛行への切替は、現在の位置・姿勢を保って即時に完了します。自由飛行から無限歩行へ切り替えると、1 秒かけて接続時の高さへ戻り、接続時の姿勢を基準とする Yaw だけを残してピッチとロールを水平へ戻します。移行中は Drag / Turn を受け付けません。

### コントローラー入力

既定の SteamVR Input バインドです。押している間、対応する操作が有効になります。

| コントローラー | Drag（空間移動） | Turn（空間回転） |
| --- | --- | --- |
| Touch 左手 / 右手 | グリップ押下 | 左 X / 右 A 押下 |
| Valve Index 左手 / 右手 | トリガー押下 | A 押下 |

`⚙` →「SteamVR のバインド設定を開く」、または `FlugelKranz.exe --bindings` から変更できます。アプリ名は `FlugelKranz`、アプリキーは `org.flugelkranz.windows` です。左右それぞれの Drag / Turn / reset_hold をボタンやタッチへ割り当てられます。上流 Linux 版のタッチ組み合わせや Index 感圧設定は使用しません。

`reset_hold` は既定では未割当です。必要に応じて SteamVR で割り当ててください。

| 入力 | 無限歩行（I） | 自由飛行（F） |
| --- | --- | --- |
| 片手の reset_hold を 1 秒保持 | 高さリセット | 水平リセット |
| 両手の reset_hold を 1 秒保持 | 自由飛行へ切替 | 無限歩行へ切替 |

両手保持のモード切替は片手リセットより優先されます。UI の `I` / `F` と `↻` も使用できます。

### 頭部操縦の試作（Windows / F モード）

F モードでは頭部操縦と強化したスティック推進が既定で有効です。設定の「自由飛行 — 頭部操縦（試作）」で変更できます。保存済みの有効／無効設定は保持します。SteamVR の開発者設定 **Experimental overlay input overrides** を有効にする必要があります。無効の場合は理由を表示して接続を終了します。

- Touch の **X / A を短押し**すると頭部操縦を ON / OFF。試作中は元のコントローラー Turn を置き換えます。短押しでボタンを離した瞬間に切り替え、ON 時の物理的な頭の向きを中立にします。ダブルクリック判定の待ち時間はありません。
- ON 中は中立からの頭の傾きで連続回転します。下向きで前転、上向きで後転、左右の傾きでロール、左右を向くと旋回します。中立へ戻すと回転指令はゼロになります。
- **X / A の 0.5 秒長押し**は移動・回転慣性をゼロにし、位置・姿勢と頭部操縦の ON/OFF は保持します。長押し後に離しても操縦状態は切り替えません。操縦 ON のまま傾けている場合やスティック入力がある場合は、その後の指令で再び動きます。
- **左スティック**は現在の視線を基準に推進します。上入力は見ている方向、下入力はその逆方向へ加速します。左右入力は無視します。頭部操縦 OFF でも推進できます。スティックを戻しても移動慣性は残ります。
- Drag は独立した設定「自由飛行 — Drag」で有効／無効を切り替えられます（既定は有効）。掴む操作は従来どおり押している間です。掴み中に無効化しても解放加速を発生させず、再有効化後はボタンを離してから掴み直します。Windows では F モードかつ Drag 有効なら、アプリ起動時や設定変更時にも飛行 OFF のまま接続して Drag を使用できます。Drag 中は手の固定操作を優先し、頭部回転指令とスティック加速は適用しません。試作を無効にすると X / A は元の Turn へ戻ります。
- **ダッシュボード表示中は全操作・移動慣性・回転慣性を停止**し、位置・姿勢を保持します。頭部操縦と入力専有も解除します。閉じた後はスティックと操作ボタンを戻し、頭部操縦は再度クリックして開始します。

試作の固定値は頭の遊び 3°、25°で最大 90°/秒（間は二次曲線）、スティックの遊び 15%、最大加速度 14 m/s²、スティック加速時の速度上限 12 m/s です。スティック推進中は移動慣性の自然減衰を止め、最大入力では約 0.86 秒で速度上限に達します。スティックを戻すと既存の減衰設定を使用します。回転慣性の減衰と速度ベクトルの回転は従来の設定を維持します。以前依頼された OVRAS 相当の既定値調整とは別です。

試作を有効にした F モードのアプリ ON 中だけ、左スティックと X / A の入力元を高優先度で専有します。VRChat のバインドを削除する必要はありません。右スティック押し込みや B は使いません。既存の個人バインドには `/actions/pilot` の新規割当がない場合があるため、SteamVR で確認してください。Index の既定は左右 A です。

この試作の入力専有・ダッシュボード・他 Overlay との共存は実機未確認です。フローティングパネルの操作検出は未実装で、表示されただけでは専有を解除しません。main には描画補正の修正も統合しています。Quest 2 + Touch / Virtual Desktop では、既知のふらつきが解消したとの報告を得ています。

### 無限歩行モード

無限歩行では慣性を使いません。片手 Drag は、掴んだ手の上下移動だけを空間の Y 移動へそのまま反映します。両手 Drag は両手位置の中点を基準とし、上下移動量を 2 倍にします。横方向や前後方向へ手を動かしても Drag には反映しません。

Turn は常に HMD の位置を支点とする Y 軸回転です。片手 Turn は掴んだコントローラーの Yaw を打ち消し、両手 Turn はコントローラーの傾きではなく HMD の Yaw を打ち消します。片手と両手が切り替わった時点で現在の姿勢を新しい開始姿勢として採用するため、切替だけでは空間が跳びません。

片手の reset_hold による高さリセットは、Y 位置だけを接続時の高さへ 1 秒かけて戻します。X/Z 位置と姿勢は維持します。リセット中は操作を受け付けず、完了後は入力を離して掴み直します。

無限歩行専用の **ドラグスムーズ**は、Drag、Turn、両手 Turn の追従を個別に滑らかにします。いずれも `0.0` 秒が既定値で、`0.0`～`1.0` 秒の範囲で調整できます。`0.0` 秒では補間せず直接反映し、値を大きくすると追従が緩やかになります。

**無限歩行ブースト**は、Turn 中の HMD の水平移動を進行方向へ加えて、回転時に足が後ろへ滑る感覚を補正します。補正値は追加する移動量の倍率で、既定値は `0.6`、範囲は `0.0`～`2.0` です。`0.0` では無効、`1.0` では計測した水平移動と同じ距離を追加します。

### 自由飛行モード

片手 Drag は掴んだコントローラーの位置を空間内に固定するように全軸移動し、両手 Drag は両手位置の中点を固定します。二手目が加わると、その時点の中点で掴み直すため空間は跳びません。両手 Drag から片手を離した場合は Drag 全体を終了します。残した手の入力も一度離してから掴み直してください。

片手 Turn は掴んだコントローラーの回転を打ち消すように全軸回転します。既定の回転支点は HMD の位置です。設定で有効な HMD・左右コントローラー位置の中点へ変更できます。Drag と Turn を同時に使用している間は、この設定よりも Drag の手、または両手 Drag の中点を支点として優先します。

両手 Turn は二つのコントローラーを結ぶ直線を軸とする回転成分だけを反映します。二手目が加わったとき、または両手から片手へ戻ったときは、その時点の位置・姿勢で掴み直し、切替から角速度を生成しません。片手 Drag ともう片手の Turn は同時に使用でき、Drag の固定点を保ったままその周囲を回転できます。

両手 Drag 中は移動慣性と回転慣性の両方へドラグブレーキをかけます。片手 Drag は移動慣性だけ、Turn は回転慣性だけを止めます。操作を離すと、その時点で計測した移動速度または角速度を慣性として引き継ぎます。

片手の reset_hold による水平リセットは、その時点で表示されている HMD の正面を最も近い水平向きへ合わせ、ピッチとロールを 1 秒かけて戻します。回転中は通常の Turn と同じ支点を固定し、同時に Drag している場合は Drag の位置を優先します。リセット中は操作を受け付けず、完了後は入力を離して掴み直します。

自由飛行モードで使う慣性パラメーターは次のとおりです。

- **慣性カットオフ**は解放速度が Drag `5 cm/s`、Turn `45 °/s` 未満なら慣性を開始しません。開始済みの慣性が減速によって閾値を下回っても停止には使用しません。チェックを外すと無効になります。
- **慣性加速倍率**は解放速度を Drag・Turn 別に `0.0`～`5.0` 倍します。既定値は Drag `5.0`、Turn `0.4` です。
- **Z加速**はプレイヤーの正面方向を基準に、Drag 解放時の前後成分だけを追加倍率で強めます。方向との内積の絶対値を重みとするため、横方向には追加加速をかけません。範囲は `1.0`～`5.0`、既定値は `2.0` です。
- **慣性加速ブーストモード**を有効にすると、Drag 中のコントローラー移動速度がカットオフを超えている間は Drag ブレーキをかけず、解放時の加速を残っている慣性へ加算します。コントローラーが再び低速または停止するとブレーキも再開します。加算後の速度は、残っている慣性と今回の解放加速の大きい方を基準に最大倍率で制限され、既定値は有効・`4.0` 倍（`1.0`～`6.0`）です。
- **ベクトル回転倍率**は Turn で現在の移動慣性ベクトルを回す割合です。既定値 `1.0` では Turn に完全追従して曲線軌道を作り、`0.0` では回転前の進行方向を維持します。
- **慣性減速**は毎秒の指数減衰率です。`0.0` は減速なし、`10.0` は急速な減速で、既定値は `2.0 /秒` です。
- **慣性減速免除**の時間は、現在速度から実用上の停止速度まで通常減速する予測時間に対する割合です。Drag と Turn を個別に設定でき、既定値は Drag `0.20`、Turn `0.15` です。免除割合の既定値は共通の `0.90` です。
- **ドラグスムーズ**は、Drag と Turn の追従を個別に滑らかにしてトラッキングの細かな揺れを抑えます。範囲は `0.0`～`1.0` 秒、既定値は Drag `0.01` 秒、Turn `0.05` 秒です。`0.0` 秒では補間せず直接反映します。慣性速度はこの設定にかかわらず実際のコントローラー操作から計算します。
- **ドラグブレーキ**は Drag / Turn を掴み始めたときに対応する慣性を完全に減衰させます。片手 Drag は線速度、Turn は角速度、両手 Drag は線速度と角速度の両方に作用します。適用時間を `0.0`～`1.0` 秒で設定でき、既定値は `0.40` 秒、`0.0` 秒なら即時停止します。発動時は対応する慣性減速免除を解除します。

HMD のトラッキングを失った間は、ON 状態、操作状態、慣性を保持したまま空間更新を一時停止し、復帰すると再開します。手のトラッキングを失った場合、その手の操作は解除されます。両手 Turn は追跡が残る手を基準に掴み直して継続します。両手 Drag は片手を失うと全体を解除するため、残る手も入力を離してから掴み直してください。

通常終了時は飛行変換を解除します。OFF 中は接続を維持して位置・姿勢を保持します。アプリの heartbeat が 500 ms 途絶えると、稼働中のドライバーは変換を解除し、復帰には再接続が必要です。接続時の SteamVR Standing 基準空間が変更された場合は操作を停止します。

## 設定保存

設定は変更時に `%USERPROFILE%/.config/FlugelKranz/config.json` へ保存されます。`FLUGELKRANZ_CONFIG` で保存先ファイルを、`XDG_CONFIG_HOME` で設定ディレクトリを変更できます。各設定のリセットボタンはその項目を既定値へ戻します。

## 構成と開発

```text
FlugelKranz.exe（Avalonia / Windows）
  ├─ Core：Drag / Turn、慣性、モード制御
  └─ DriverFlightRuntime：SteamVR Input + 共有メモリー IPC
       ├─ 変換前の物理姿勢を読み取り
       └─ 飛行変換を専用 SteamVR ドライバーへ送信
            ├─ tracked device の姿勢へ移動・回転を適用
            └─ Direct Mode のフレーム姿勢を物理 HMD 姿勢へ補正
```

ゲームへ渡す飛行後の姿勢と、HMD の表示補正に渡す物理姿勢を分けます。操作計算には変換前の姿勢を使い、飛行結果が入力に戻るフィードバックを防ぎます。Chaperone や VRChat の水平線設定は書き換えません。

開発手順は [WINDOWS.md](WINDOWS.md)、座標変換・IPC・描画補正は [ドライバー文書](native/driver/README.md)、作業規約は [AGENTS.md](AGENTS.md) を参照してください。
